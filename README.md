# Todo Application

A simple Todo Application built using HTML, CSS, JavaScript, and Bootstrap. The application allows users to create, manage, save, and delete tasks. Tasks are stored in the browser using Local Storage, allowing them to persist even after refreshing the page.

## Live Demo

https://kathrinenancy.github.io/todo_application/

---

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using Local Storage
- Tasks remain available after refreshing the page
- Responsive user interface

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 4.5
- Local Storage

## How It Works

1. Enter a task in the input field.
2. Click **Add** to create a new task.
3. Mark tasks as completed using the checkbox.
4. Delete tasks using the delete icon.
5. Click **Save** to store tasks in Local Storage.
6. Refresh the page to see the saved tasks.
